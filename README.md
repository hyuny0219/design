# 🤖 미로 탈출 코딩 챌린지 (삼성 드림캠퍼스 부스용)

중학생 대상 **체험형 코딩/IT 부스**를 위한 웹 기반 미로 탈출 게임입니다.
명령 블록(앞으로 · 왼쪽/오른쪽 돌기 · **반복문**)을 직접 조립해 로봇을 ⭐ 별까지 이동시키며,
**순차 실행 → 방향 전환 → 디버깅 → 반복문**의 코딩 핵심 개념을 손으로 익힙니다.

## ▶ 실행 방법 (설치/빌드 불필요)
- `index.html` 파일을 **웹 브라우저로 더블클릭**하면 끝입니다. (인터넷 연결 불필요)
- 부스 노트북·태블릿 어디서나 바로 사용 가능하며, 클릭/터치 모두 지원합니다.

## 🎮 구성
- **명령 블록**: `앞으로`, `왼쪽 돌기`, `오른쪽 돌기`, `🔁 반복하기`(횟수 1~9 조절)
- **실행 / 한 단계 / 처음으로 / 지우기** 버튼, 속도 조절(느리게·보통·빠르게)
- **별점(⭐)**: 더 적은 블록으로 풀수록 높은 점수 → "효율적인 코드" 동기 부여

## 🧩 레벨 & 학습 개념
| 레벨 | 주제 | 배우는 개념 |
|---|---|---|
| 1 | 직진하기 | 순차 실행 |
| 2 | 모퉁이 돌기 | 방향 전환 |
| 3 | 두 번 꺾기 | 디버깅(벽에 부딪히면 틀린 명령 찾기) |
| 4 | 반복문의 힘 | 반복문(loop) |
| 5 | 긴 복도 | 반복 횟수로 효율적인 코드 만들기 |

## 💡 부스 운영 팁
- 벽에 부딪히면 해당 명령이 **빨간색**으로 표시됩니다 → "어디가 틀렸을까?" 디버깅 대화 유도.
- `한 단계` 버튼으로 천천히 실행하며 로봇의 움직임을 함께 관찰하면 이해가 빨라집니다.
- 레벨 4~5에서 "반복문 없이 vs 반복문 사용" 블록 수를 비교해 보여주면 효과적입니다.
